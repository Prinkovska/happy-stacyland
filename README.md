## Як працювати з іншого комп'ютера

### Один раз — підготовка
1. Встановіть **Claude** (десктопний застосунок) і увійдіть у свій акаунт.
2. Встановіть **Git**: https://git-scm.com/download/win
3. Встановіть **GitHub CLI**: https://cli.github.com
4. Відкрийте термінал (PowerShell) і увійдіть у GitHub:
   ```
   gh auth login
   ```
   Оберіть GitHub.com → HTTPS → увійти через браузер.
5. Завантажте проєкт у зручну папку:
   ```
   gh repo clone Prinkovska/happy-stacyland
   ```
6. Відкрийте папку `happy-stacyland` у Claude на вкладці **Code** і напишіть:
   «Прочитай README, CLAUDE.md і docs/STRUCTURE.md і продовжуємо».

### Щоразу
- **Почали роботу** → попросіть Claude: «підтягни останні зміни» (`git pull`).
- **Закінчили** → «закоміть і відправ на GitHub» (`git commit` + `git push`).
- Сайт за посиланням оновлюється сам приблизно за хвилину після відправлення.
- Не правте одні й ті самі файли на двох комп'ютерах одночасно, не синхронізувавши.

### Переглянути сайт на своєму комп'ютері
Попросіть Claude «запусти локальний перегляд» — він запустить сервер (`.claude/serve.ps1`)
і відкриє http://localhost:5173/site/index.html.
На Mac цей сервер не працює — Claude підбере інший спосіб.

### Чого немає в репозиторії
Сирі фото, відео `hero_video.mp4`, логотип у PSD, документи (docx, pdf, xlsx) лежать **лише на
першому комп'ютері** (папка `Stacyland`). На сайті вже стиснуті версії. Якщо на іншому комп'ютері
треба буде обробити нові фото — скопіюйте їх у папку проєкту вручну (флешка, Google Диск).

## Ключові рішення (чому так, а не інакше)

- **Код, а не Tilda.** Сайт — чистий HTML/CSS/JS, хостинг Vercel (поки — GitHub Pages).
  Вимоги з «Базового промпту» під Tilda (CONFIG у TXT, `!important`) більше не діють.
- **Палітра:** жовтий `#FFC700`, синій `#0B2D61`, зелений `#6CAB3C`, світлий `#F2F4F8`, крем `#F7F3E8`.
  Стара палітра з ТЗ і PDF (`#F7D318 / #113D8D / #8BC53F`) — застаріла.
- **Логотип** — справжній, із серцем. ШІ-логотип із короною з картинки-брендбуку не використовуємо.
  У шапці — собачка з серцем без фону + логотипи UKU/FCI.
- **Шрифти:** M PLUS Rounded 1c (заголовки), Nunito (текст), Caveat (рукописні підписи).
  Baloo 2 зі старого коду **не має кирилиці**. Шрифти можна змінити в одному місці — на початку `site/css/style.css`.
- **Як підписувати:** «Анастасія Пріньковська (Довгань)» — старе прізвище поруч, бо багато хто знає за ним.
  Роль — «Заводчик-кінолог, власниця розплідника».
- **Цуценят зараз немає** (приплід — 2027), тому головна дія сайту — **анкета і лист очікування**.
- **Плашки в Hero** не повторюють бейдж і підзаголовок: «15+ років з породою», «Чемпіонські лінії», «Здорові коліна в 4 поколіннях».
- **Візити:** можна приїхати в Чернівці за домовленістю; поки цуценята не вакциновані — лише подивитися, на руки не брати.
- **Передача цуценят** — по всій Україні і за кордон.
- **Працюємо поблоково:** спершу обговорюємо блок, потім верстаємо; правимо лише те, про що домовились.

## Технічна примітка для першого комп'ютера
Папка проєкту на першому комп'ютері записана на іншого користувача Windows, тому Git її блокує.
Claude обходить це разово для своїх команд. Якщо запускати Git самостійно, один раз виконайте:
```
git config --global --add safe.directory "E:/Anastasia/Работы/Сайти/Stacyland"
```
